# JobBoard

JobBoard is a Flask web application created as a final Python/Flask project.

The application allows users to browse job vacancies, create accounts, log in, publish job posts, edit their own posts, and manage their profiles.

## Live Website

https://jobboard-vt1m.onrender.com

> The project is hosted on Render's free service. If the application has been inactive, the first request may take some time to load.

## Features

- User registration
- User login and logout
- Authentication and authorization
- User profile management
- Profile picture upload
- Create job posts
- View job posts
- Edit own job posts
- Delete own job posts
- Permission control for posts
- Job detail pages
- Public author profiles
- Job image upload
- Job categories
- Job search
- Sorting by date
- External API integration
- CSRF protection with Flask-WTF
- Custom 404 and 500 error pages
- Application logging
- Automated tests
